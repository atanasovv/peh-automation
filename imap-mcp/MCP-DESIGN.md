# Пощенски MCP за Codex — актуален обхват 0.2.0

Go услуга с основно внедряване в контейнер на отдалечен сървър. Клиентът се
свързва със Streamable HTTP на HTTPS URL с Bearer токен. Локалното stdio
стартиране остава поддържано.

Съществуващият Traefik обслужва TLS чрез входната точка websecure, resolver
letsencrypt и външната мрежа peh. Compose добавя отделен Host и основен маршрут /, със съвместим адрес /mcp.
Паролата на пощата и токенът се задават чрез средата на услугата. Паролата се
използва само от пощенската услуга, а клиентът получава отделния MCP токен.
HTTP достъпът е за една кутия и един доверен потребител.

Трите инструмента търсят писма, четат текстовите им части и добавят отговор
в сървърната папка Drafts. IMAP връзката използва TLS на порт 993, а четенето
е с EXAMINE и BODY.PEEK. Сървърът има само IMAP клиент. Прегледът и изпращането
на черновите се извършват от потребителя в Outlook.

Codex съчетава важната информация от писмата със съществуващия MCP за задачи.
Текущата версия обработва текстови части и се използва при поискване.
Обработеното съдържание влиза в контекста на разговора.

Проверките включват HTTP удостоверяване, допустим Host и Origin, откриване
на инструментите, форматиране на чернови и компилиране. Предстои проверка с
реалната кутия и синхронизацията на черновите с Outlook след деплойване.
